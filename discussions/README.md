# Discussions

Har phase ka design document — **code likhne se pehle**.

Niyam ek hi hai: **jab tak clarity nahi, tab tak aage nahi.**
Sawaal, disagreement, ya "ye samajh nahi aaya" — sab yahin discuss hoga, phir build.

Har document mein ye hoga:

- **Kya ban raha hai** — aur kya jaanbujh ke nahi ban raha
- **System design** — mermaid + ASCII diagrams
- **Kaise banayenge** — step by step order
- **Faisle aur unki wajah** — har faisle ka kharcha bhi likha hua
- **Sawaal** — jinka jawab chahiye aage badhne se pehle
